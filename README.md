# Food-Delivery-DSA
This Food Delivery Management System project utilizes core Data Structures and Algorithms (DSA) concepts, such as queues for order processing, stacks for order history, and linked lists for menu or customer management, while also integrating file handling for data persistence. The program allows users to manage food items, place orders, and maintain customer records, with data stored in external files . The user is responsible for creating and managing input files, following the specified format to ensure smooth operation. This system simulates a food delivery service, where the menu, orders, and customer details are all read and written to files, providing a simple yet effective implementation of file handling in a DSA-based project.
